# Hlongwane Enterprise Frontend

Customer-facing frontend for the Hlongwane Enterprise device commerce platform.

## Stack

- Vite
- React
- TypeScript
- Chakra UI
- Apollo Client
- React Router
- Supabase
- Yarn

## Setup

```bash
cp .env.example .env
yarn install
yarn dev
```

Frontend: `http://localhost:5173`

The GraphQL API defaults to `http://localhost:4000/graphql`.
